# 草莓作物模拟系统 - 产品需求文档 (PRD)

## 1. 产品概述

基于 DSSAT CROPGRO-Strawberry 作物模型的纯前端草莓生长模拟与决策支持系统。将原本依赖 Windows 桌面环境的 Fortran 作物模型移植到浏览器端，让农业研究人员、种植户和学生在无需安装任何软件的情况下，即可进行草莓生长模拟、产量预测和管理策略优化。

- 目标用户：农业科研人员、草莓种植户、农学专业师生
- 核心价值：零安装、跨平台、即开即用的草莓生长模拟工具

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 研究人员 | 直接访问 | 配置全部参数、运行模拟、导出数据 |
| 种植户 | 直接访问 | 选择品种/地区、查看产量预测、管理建议 |
| 学生 | 直接访问 | 使用预设数据学习作物模型原理 |

### 2.2 功能模块

1. **模拟配置页**：气象参数、土壤参数、品种选择、管理措施配置
2. **模拟运行页**：实时模拟进度、关键指标仪表盘、日步长状态展示
3. **结果分析页**：生长曲线图表、产量分布、品质预测、策略对比
4. **品种参数库页**：内置品种参数浏览与编辑、自定义品种创建
5. **数据管理页**：导入/导出 DSSAT 格式文件、模拟历史管理

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 模拟运行页 | 实时仪表盘 | 显示当前生育期、LAI、生物量、果实产量等关键指标 |

| 数据管理页 | 历史记录 | 浏览和管理本地存储的模拟历史 |

## 4. 用户界面设计

### 4.1 设计风格

- **主题色**：以草莓红 (#E63946) 为主色，搭配自然绿 (#2D6A4F) 作为辅助色，深色背景 (#1A1B2E) 营造专业科研氛围
- **按钮风格**：圆角胶囊按钮，主按钮使用草莓红渐变，次按钮使用半透明玻璃质感
- **字体**：标题使用 DM Serif Display（优雅学术感），正文使用 DM Sans（清晰易读）
- **布局风格**：左侧导航栏 + 主内容区的仪表盘布局，卡片式模块组织
- **图标风格**：线性图标（Lucide），搭配微妙的渐变和阴影

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 模拟配置页 | 气象参数 | 表单卡片，温度/降雨/辐射输入框，气象数据预览图表，文件上传拖拽区 |
| 模拟配置页 | 土壤参数 | 层级可视化编辑器，土壤剖面图，参数滑块 |
| 模拟配置页 | 品种选择 | 卡片式品种列表，参数对比面板，搜索筛选 |
| 模拟配置页 | 管理措施 | 时间轴式管理事件编辑器，日历选择器 |
| 模拟运行页 | 实时仪表盘 | 环形进度条，数字指标卡片，迷你趋势图，状态指示灯 |
| 结果分析页 | 生长曲线 | ECharts 交互式折线图，支持缩放/筛选/下载 |
| 结果分析页 | 产量分析 | 柱状图+饼图组合，月度产量热力图 |
| 结果分析页 | 品质预测 | 雷达图+散点图，品质等级色带 |
| 结果分析页 | 策略对比 | 多系列叠加图表，差异高亮标注 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 平板端（768-1024px）：侧边栏折叠为图标模式
- 移动端（<768px）：底部导航栏，卡片单列布局

### 4.4 动效设计

- 页面切换：淡入淡出 + 轻微上移
- 卡片加载：骨架屏渐显
- 模拟运行：进度条脉冲动画，数据点实时刷新
- 图表交互：悬停高亮，点击展开详情
