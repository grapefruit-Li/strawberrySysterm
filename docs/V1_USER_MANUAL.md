# StrawSim 版本一 · 模拟器模式 使用手册

## 1. 版本概述

版本一是**经典模拟器模式**，采用"配置→模拟→分析"的工作流程。用户手动配置气象、土壤、品种和管理参数，运行模拟后分析结果。适合农业研究人员、模型开发者和高级用户。

## 2. 进入方式

打开系统后，在版本选择页面点击**"进入版本一"**按钮，或直接访问 `/v1` 路径。

## 3. 页面导航

| 路由 | 页面 | 功能 |
|------|------|------|
| `/v1` | 模拟配置 | 配置气象、土壤、品种、管理参数 |
| `/v1/simulation` | 模拟运行 | 运行模拟、查看实时仪表盘 |
| `/v1/results` | 结果分析 | 查看生长曲线、产量、品质图表 |
| `/v1/cultivars` | 品种参数库 | 浏览和编辑品种参数 |
| `/v1/data` | 数据管理 | 导入/导出文件、管理模拟历史 |

## 4. 操作流程

### 4.1 配置参数

进入模拟配置页面（默认首页），在四个标签页中分别配置：

#### 气象参数
- **站点信息**：设置站点名称、纬度、经度、海拔
- **逐日气象数据**：查看辐射(MJ/m²)、最高温(℃)、最低温(℃)、降水(mm)等气象数据表格
- **文件导入**：拖放或选择 `.WTH` 格式的 DSSAT 气象文件

#### 土壤参数
- **土壤剖面配置**：逐层设置土壤深度(cm)、容重(g/cm³)、砂粒(%)、粘粒(%)、有机质(%)、pH、有效含水量
- 支持添加/删除土层，支持 `.SOL` 文件导入

#### 品种选择
- 设置品种名称、出苗天数、开花天数、成熟天数
- 配置最大LAI、潜在果重(g)、目标可溶性固形物(%)、目标酸度(%)

#### 管理措施
- **种植信息**：设置定植日期和种植密度(株/ha)
- **灌溉事件**：添加/删除灌溉事件，设置日期、灌溉量(mm)、灌溉方式（滴灌/喷灌/漫灌）
- **施肥事件**：添加/删除施肥事件，设置日期、施肥量(kg/ha)、肥料类型

点击**"加载预设数据"**可快速加载内置的佛罗里达草莓种植数据。

### 4.2 运行模拟

1. 配置完成后点击**"开始模拟"**
2. 系统自动跳转到模拟运行页面

#### 控制面板
- **启动/暂停/重置**模拟
- **速度调节**：1x - 10x 滑块控制模拟速度
- **进度条**：显示模拟完成百分比

#### 实时仪表盘（7个统计卡片）
| 卡片 | 内容 |
|------|------|
| 当前天数 | 模拟运行天数 |
| 生育阶段 | 当前物候阶段名称 |
| LAI | 叶面积指数 |
| 总生物量 | 单位 kg/ha |
| 果实重 | 单位 kg/ha（草莓色高亮） |
| 水分胁迫 | 数值 > 0.2 时显示琥珀色警告 |
| 氮素胁迫 | 数值 > 0.2 时显示琥珀色警告 |

#### LAI趋势图
ECharts 面积图展示叶面积指数随时间的变化趋势。

#### 事件日志
实时滚动显示模拟过程中的事件，带有图标和颜色标识：
- ⚠️ 警告事件（琥珀色）
- ✅ 成功事件（绿色）
- ℹ️ 信息事件（蓝色）

### 4.3 分析结果

模拟完成后进入结果分析页面，四个标签页：

#### 生长曲线
多线折线图展示以下指标随时间的变化：
- LAI（叶面积指数）
- 总生物量
- 叶片重、茎重、根重、果实重

#### 产量分析
- **产量摘要卡片**：总产量(kg/ha)、果实数量(个/ha)、平均果重(g)、采收日期
- **月度产量柱状图**：按月汇总的产量分布

#### 品质预测
散点图展示随采收日期变化的品质指标：
- 可溶性固形物 SSC（%）
- 酸度（×10）
- 硬度（kg/cm²）

#### 策略对比
支持多次模拟运行的结果对比（功能待完善）。

#### 数据导出
支持导出模拟结果为 **CSV** 或 **JSON** 格式。

### 4.4 品种参数库

- 以卡片网格浏览所有品种，每张卡片显示品种名、生态型、产地、描述
- 关键参数摘要：最大LAI、潜在果重、固形物目标值
- 点击展开按钮查看完整参数详情，包括耐寒性和抗病性可视化进度条
- **添加自定义品种**：弹窗表单支持填写品种名称、生态型、产地、描述及全部参数
- 点击品种卡片可选中该品种

### 4.5 数据管理

#### 文件导入
- 支持拖放或点击上传 DSSAT 格式文件（`.WTH`/`.SOL`/`.CUL`/`.SPE`/`.ECO`）
- 已上传文件列表显示文件类型标签（彩色徽章）、文件名、行数、解析状态
- 支持单个删除或清空全部

#### 数据导出
- 导出当前完整配置（气象+土壤+品种+管理）为 JSON 文件

#### 模拟历史
- 浏览和管理本地存储的模拟历史记录
- 每条记录显示名称、日期时间、状态、模拟天数

## 5. 核心算法

版本一使用 DSSAT CROPGRO-Strawberry 作物模型，包含以下模块：

| 模块 | 功能 |
|------|------|
| 物候发育 | 积温(GDD)计算、生育阶段转换、光周期效应 |
| 光合生产 | 冠层光合、维持呼吸、生长呼吸、干物质分配 |
| 土壤水分 | Priestley-Taylor PET、蒸发、蒸腾、SCS径流 |
| 土壤氮素 | 矿化、硝化、反硝化、植物氮吸收 |
| 草莓专用 | 连续开花结果、同化物分配、多次采收 |
| 品质预测 | SSC、酸度、硬度预测 |
| 胁迫因子 | 水分/氮素/温度胁迫计算 |

## 6. 日步长迭代流程

```
每日循环:
  1. 读取当日气象数据 (srad, tmax, tmin, rain)
  2. 计算土壤水分平衡 (蒸发、蒸腾、径流、渗漏)
  3. 计算土壤氮素平衡 (矿化、硝化、吸收)
  4. 计算物候发育速率 (积温、生育期推进)
  5. 计算冠层光合与呼吸
  6. 计算干物质分配 (叶/茎/根/果实)
  7. 草莓专用: 连续开花结果、多次采收
  8. 计算水分/氮素胁迫因子
  9. 更新植物和土壤状态
  10. 检查采收事件，记录产量和品质
  11. 输出当日结果
```

## 7. 内置数据

- **气象数据**：佛罗里达 Balm 站点（2020年10月-2021年3月）
- **土壤数据**：佛罗里达 Myakka 细砂土（5层剖面）
- **品种数据**：Florida Radiance 和 Florida Brilliance
- **物种参数**：CROPGRO-Strawberry 完整物种参数
