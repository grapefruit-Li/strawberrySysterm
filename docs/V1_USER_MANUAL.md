# StrawSim 版本一 · 模拟器模式 使用手册

## 1. 版本概述

版本一是**经典模拟器模式**，采用"配置→模拟→分析"的工作流程。用户手动配置气象、土壤、品种和管理参数，运行模拟后分析结果。适合农业研究人员、模型开发者和高级用户。

## 2. 进入方式

打开系统后，在版本选择页面点击**"进入版本一"**按钮，或直接访问 `/v1` 路径。

## 3. 页面导航

| 路由 | 页面 | 功能 |
|------|------|------|
| `/v1` | 模拟配置 | 配置气象、土壤、品种、管理参数 |
| `/v1/simulation` | 模拟运行 | 运行模拟、查看实时仪表盘 |
| `/v1/results` | 结果分析 | 查看生长曲线、产量、品质图表 |
| `/v1/cultivars` | 品种参数库 | 浏览和编辑品种参数 |
| `/v1/data` | 数据管理 | 导入/导出文件、管理模拟历史 |

## 4. 操作流程

### 4.1 配置参数

1. 进入模拟配置页面（默认首页）
2. 在四个标签页中分别配置：
   - **气象参数**：手动输入或导入 .WTH 格式气象数据
   - **土壤参数**：配置土壤层级和水分特征参数，支持 .SOL 文件导入
   - **品种选择**：从内置品种库选择（Florida Radiance、Florida Brilliance 等）
   - **管理措施**：设置播种日期、密度、灌溉和施肥方案
3. 点击"加载预设数据"可快速加载内置的佛罗里达草莓种植数据

### 4.2 运行模拟

1. 配置完成后点击"开始模拟"
2. 系统自动跳转到模拟运行页面
3. 可通过控制面板：
   - 启动/暂停/重置模拟
   - 调节模拟速度
4. 实时仪表盘显示关键指标：
   - 当前天数、生育阶段
   - LAI（叶面积指数）
   - 总生物量、果实重
   - 水分胁迫、氮素胁迫

### 4.3 分析结果

1. 模拟完成后进入结果分析页面
2. 四个分析标签页：
   - **生长曲线**：LAI、生物量、叶/茎/根/果实干重随时间变化
   - **产量分析**：累积产量、单次采收量、月度产量分布
   - **品质预测**：可溶性固形物(SSC)、酸度、硬度变化趋势
   - **策略对比**：不同管理方案的模拟结果对比
3. 支持导出结果为 CSV 或 JSON 格式

### 4.4 品种参数库

- 浏览内置品种的遗传参数、生态型参数和物种参数
- 编辑现有品种参数
- 添加自定义品种

### 4.5 数据管理

- **文件导入**：上传 DSSAT 格式文件（.WTH/.SOL/.CUL/.SPE/.ECO）
- **数据导出**：导出模拟结果和参数配置
- **模拟历史**：浏览和管理本地存储的模拟历史

## 5. 核心算法

版本一使用 DSSAT CROPGRO-Strawberry 作物模型，包含以下模块：

| 模块 | 功能 |
|------|------|
| 物候发育 | 积温(GDD)计算、生育阶段转换、光周期效应 |
| 光合生产 | 冠层光合、维持呼吸、生长呼吸、干物质分配 |
| 土壤水分 | Priestley-Taylor PET、蒸发、蒸腾、SCS径流 |
| 土壤氮素 | 矿化、硝化、反硝化、植物氮吸收 |
| 草莓专用 | 连续开花结果、同化物分配、多次采收 |
| 品质预测 | SSC、酸度、硬度预测 |
| 胁迫因子 | 水分/氮素/温度胁迫计算 |

## 6. 内置数据

- **气象数据**：佛罗里达 Balm 站点（2020年10月-2021年3月）
- **土壤数据**：佛罗里达 Myakka 细砂土（5层剖面）
- **品种数据**：Florida Radiance 和 Florida Brilliance
- **物种参数**：CROPGRO-Strawberry 完整物种参数

## 7. 返回版本选择

点击页面左上角"返回版本选择"按钮，可回到版本选择页面切换到版本二。
