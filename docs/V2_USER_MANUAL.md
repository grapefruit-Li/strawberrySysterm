# StrawSim 版本二 · 决策引擎模式 使用手册

## 1. 版本概述

版本二是**链式决策引擎模式**，采用"物候→产量→病虫害→农事操作"的闭环决策流程。系统根据品种参数和气候数据自动预测生长节点、评估病虫害风险、推荐农事操作。适合草莓种植户、农场管理者和农技人员。

## 2. 进入方式

打开系统后，在版本选择页面点击**"进入版本二"**按钮，或直接访问 `/v2` 路径。

## 3. 页面导航

| 路由 | 页面 | 功能 |
|------|------|------|
| `/v2` | 基础信息 | 品种选择、区域选择、定植配置 |
| `/v2/phenology` | 物候方案 | GDD时间轴、生长阶段预测 |
| `/v2/pest` | 植保IPM | 病虫害风险预警、防治建议 |
| `/v2/operations` | 农事操作 | 灌溉/施肥方案推荐 |
| `/v2/yield` | 产量预测 | 逐日产量曲线、品质预测 |

## 4. 操作流程

### 4.1 基础信息配置

1. 进入基础信息页面（默认首页）
2. **品种选择**：
   - 从20余个品种卡片中选择（前5个有真实数据，其余为估算数据）
   - 品种类型筛选：短日型 / 日中性
   - 每个品种卡片显示：品种名、类型、单果重、SSC、硬度、需冷量
   - 数据可信度标识：高可信度（绿色徽章）或估算数据（黄色徽章）
3. **种植区域选择**：
   - 佛罗里达（亚热带气候）
   - 加利福尼亚（地中海气候）
   - 上海（亚热带季风气候）
   - 昆明（亚热带高原气候）
   - 每个区域卡片显示气候特征和年均温
4. **定植配置**：
   - 选择定植日期
   - 设置种植密度
5. 点击**"生成方案"**按钮，系统自动运行模拟并生成全链路决策方案

### 4.2 物候方案

1. 顶部指标卡片：
   - 当前累积GDD（积温）
   - 当前生长阶段
   - 距下一阶段天数
   - 预计采收开始日期
2. **甘特图时间轴**：
   - 横向条形图展示各生长阶段持续时间
   - 标注阶段转换的GDD阈值
   - 今日标记线
3. **GDD累积曲线**：
   - 面积图展示逐日积温累积
   - 阶段转换节点标记
4. **物候事件列表**：
   - 花芽分化、开花、果实膨大、采收开始、采收高峰、采收结束的预测日期
   - 每个事件的GDD累积值和置信度

### 4.3 植保IPM（病虫害综合防治）

1. 顶部风险概览卡片：
   - 当前整体风险等级
   - 高风险病虫害数量
   - 下次预警时间
2. **风险指数折线图**：
   - 各病虫害风险指数随时间变化
   - 灰霉病、白粉病、红蜘蛛、炭疽病、蚜虫
3. **病虫害预警卡片**：
   - 风险等级标识（绿色/黄色/橙色/红色）
   - 病虫害描述
   - 防治建议
   - 关联的生长阶段
4. **防治日历**：
   - 按时间排列的预防措施建议
5. **IPM策略概览**：
   - 综合防治策略说明

#### 主要病虫害预警逻辑

| 病虫害 | 高风险条件 | 关联阶段 |
|--------|-----------|----------|
| 灰霉病 | 开花期 + 高湿 + 15-25°C | 开花期、结果期 |
| 白粉病 | 干燥 + 温暖 + 低湿 | 营养生长期 |
| 红蜘蛛 | 高温 + 干旱 | 全生育期 |
| 炭疽病 | 结果期 + 降雨 | 结果期、采收期 |
| 蚜虫 | 温暖春季 | 营养生长期、开花期 |

### 4.4 农事操作

1. 顶部操作概览卡片：
   - 今日推荐操作
   - 本周操作数量
   - 高优先级操作数
2. **操作时间轴**：
   - 按生长阶段分组的操作时间线
   - 每个操作显示类型图标、日期、描述、优先级
3. **操作详情卡片**：
   - 操作类型：灌溉、施肥、修剪、采收、植保、其他
   - 优先级：低/中/高/紧急
   - 关联的生长阶段
   - 具体参数（灌溉量、EC值、NPK比例等）
4. **灌溉方案表**：
   - 日期、灌溉量(mm)、EC值
5. **施肥方案表**：
   - 日期、氮磷钾比例、施用量

#### 主要操作推荐逻辑

| 生长阶段 | 推荐操作 |
|----------|----------|
| 定植前 | 整地、起垄、土壤消毒 |
| 营养生长期 | 氮肥追施、灌溉调度、蚜虫监测 |
| 开花期 | 增钾减氮、灰霉病预防喷药、调节EC |
| 结果期 | 调整灌溉EC、增加排液率、炭疽病防治 |
| 采收期 | 采收调度、品质监测、持续灌溉 |
| 采收后 | 修剪、清园、土壤改良 |

### 4.5 产量预测

1. 顶部关键指标卡片：
   - 预计总产量
   - 预计平均单果重
   - 采收天数
   - 平均可溶性固形物(SSC)
2. **逐日产量曲线**：
   - 日产量和累积产量双轴图
3. **产量分布图**：
   - 按月份或采收批次的产量柱状图
4. **品质预测图**：
   - SSC、酸度、硬度随采收日期的散点图
5. **导出功能**：
   - 导出为 CSV 或 JSON 格式

## 5. 核心算法

版本二使用与版本一完全相同的 DSSAT CROPGRO-Strawberry 模型引擎，额外增加了：

| 模块 | 功能 | 版本二新增 |
|------|------|-----------|
| 物候发育 | GDD计算、阶段转换 | ✅ 共享 |
| 光合生产 | 冠层光合、呼吸、分配 | ✅ 共享 |
| 土壤水分 | PET、蒸发、蒸腾、径流 | ✅ 共享 |
| 土壤氮素 | 矿化、硝化、吸收 | ✅ 共享 |
| 草莓专用 | 连续开花、多次采收 | ✅ 增强版（光热年龄） |
| 品质预测 | SSC、酸度、硬度 | ✅ 共享 |
| 胁迫因子 | 水/氮/温度胁迫 | ✅ 共享 |
| **病虫害风险** | 5种病虫害阶段+气象风险预警 | 🆕 新增 |
| **农事操作** | 基于阶段和风险的智能推荐 | 🆕 新增 |
