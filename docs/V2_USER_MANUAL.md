# StrawSim 版本二 · 决策引擎模式 使用手册

## 1. 版本概述

版本二是**链式决策引擎模式**，采用"物候→产量→病虫害→农事操作"的闭环决策流程。系统根据品种参数和气候数据自动预测生长节点、评估病虫害风险、推荐农事操作。适合草莓种植户、农场管理者和农技人员。

## 2. 设计主题

版本二采用**浅色主题设计**，界面风格明亮清爽：
- **主背景**：浅灰色（`bg-gray-50`）
- **侧边栏**：紫色渐变（`from-violet-950 via-purple-900 to-indigo-950`），营造专业感
- **顶部头栏**：纯白背景（`bg-white`），简洁大气
- **激活导航**：白色半透明背景 + 红色左边框（`border-red-400`）
- **文字色彩**：深灰色系（`text-gray-800`），确保高对比度和可读性
- **交互反馈**：悬停变色、过渡动画，操作流畅自然

## 3. 进入方式

打开系统后，在版本选择页面点击**"进入版本二"**按钮，或直接访问 `/v2` 路径。

## 6. 各页面详细说明

### 6.1 基础信息

**路由**：`/v2`（默认首页）

#### 页面功能
本页面是决策引擎的起点，用户在此完成品种选择、种植区域选择和定植配置三项基础设置，为后续所有决策提供输入数据。

#### 组件说明

##### 品种选择（搜索+筛选+卡片网格）
- **搜索功能**：输入品种名称快速定位目标品种
- **类型筛选**：按"短日型"或"日中性"过滤品种
- **卡片网格**：每个品种卡片包含以下信息：
  - 品种名称、类型标签
  - 单果重、SSC（可溶性固形物）、硬度、需冷量
  - 数据可信度标识：🟢 高可信度（绿色徽章，前5个真实数据品种）| 🟡 估算数据（黄色徽章）
- **交互方式**：点击品种卡片选中（高亮边框），再次点击取消选中

##### 种植区域选择
- 区域卡片展示：佛罗里达（亚热带）、加利福尼亚（地中海）、上海（亚热带季风）、昆明（亚热带高原）
- 每张卡片显示：气候类型、年均温、气候特点描述
- **交互方式**：单选模式，点击卡片选中区域

##### 定植配置（日期+密度）
- **定植日期**：日期选择器，设置种植起始日期
- **种植密度**：输入种植密度（株/ha）

#### 操作流程
1. 选择品种（可多选，最多选择3个品种进行对比）
2. 选择种植区域（单选）
3. 配置定植日期和密度
4. 点击**"生成方案"**按钮，系统自动运行模拟并生成全链路决策方案

### 6.2 物候方案

**路由**：`/v2/phenology`

#### 页面功能
基于积温（GDD）模型预测各生育阶段的时间节点，以可视化图表展示物候发育全过程。物候方案是整个决策链的**核心驱动**——后续的产量预测、病虫害预警和农事操作都依赖于物候阶段的判断。

#### 组件说明

##### 摘要指标卡片（4个关键指标）
| 卡片 | 含义 |
|------|------|
| GDD（积温） | 当前累积积温值，驱动所有物候阶段转换 |
| 当前阶段 | 当前所处的生育阶段名称 |
| 距下阶段 | 距离进入下一生育阶段的预计天数 |
| 预计采收 | 预测的首次采收开始日期 |

##### 甘特图时间轴
- 横向条形图展示各生长阶段的起止时间和持续天数
- 标注阶段转换的GDD阈值（如营养生长期→开花期：GDD ≥ X）
- **今日标记线**：红色竖线标识当前日期位置
- 颜色编码区分不同阶段（营养生长期、开花期、结果期、采收期等）

##### GDD累积曲线
- 面积图展示逐日积温累积趋势
- 标记关键阶段转换节点（带标签的标记点）
- X轴为日期，Y轴为累积GDD值

##### 物候事件列表
| 事件 | 显示信息 |
|------|---------|
| 花芽分化 | 预测日期、GDD累积值、置信度 |
| 始花期 | 预测日期、GDD累积值、置信度 |
| 果实膨大 | 预测日期、GDD累积值、置信度 |
| 采收开始 | 预测日期、GDD累积值、置信度 |
| 采收高峰 | 预测日期、GDD累积值、置信度 |
| 采收结束 | 预测日期、GDD累积值、置信度 |

##### 阶段GDD进度
- 当前阶段的GDD完成进度条
- 显示当前GDD值和阶段目标GDD值
- 进度条颜色随完成度变化（<50%蓝色、50%-80%绿色、>80%深绿）

### 6.3 植保IPM

**路由**：`/v2/pest`

#### 页面功能
综合病虫害管理（Integrated Pest Management, IPM）预警与防治方案。系统根据**当前物候阶段 + 气象条件 + 品种抗病性**综合评估病虫害风险，提供预防、监测、防治的全流程建议。

#### 组件说明

##### 风险摘要卡片
| 卡片 | 含义 |
|------|------|
| 当前风险等级 | 整体风险评估（低/中/高/紧急），颜色编码 |
| 高风险病虫害数 | 风险等级≥高的病虫害数量 |
| 下次预警时间 | 下一次风险重新评估的时间 |

##### 风险预警指数图
- 多线折线图展示各病虫害风险指数随时间的变化趋势
- 涵盖5种主要病虫害：灰霉病、白粉病、红蜘蛛、炭疽病、蚜虫
- Y轴为风险指数（0-100），标注高/中/低风险阈值线
- **交互**：悬停显示当日各病虫害的具体风险值和影响因素

##### 病虫害预警卡片（网格布局）
每张卡片包含：
- **风险等级标识**：颜色圆点（🟢低 / 🟡中 / 🟠高 / 🔴紧急）
- **病虫害名称和图标**
- **风险描述**：触发高风险的条件说明
- **防治建议**：推荐的具体防治措施
- **关联生长阶段**：该病虫害高发的物候阶段标签
- **气象因素**：温湿度、降雨等触发条件

##### IPM策略面板（4个策略模块）

**1. 预防为主**
- 种植前土壤消毒建议
- 抗病品种选择建议
- 合理密植和通风管理
- 清洁田园、减少病原基数

**2. 监测预警**
- 定期田间巡查计划
- 黄板/蓝板诱虫监测
- 气象条件风险预警
- 物候阶段关联预警

**3. 综合防治**
- 生物防治（天敌引入、生物农药）
- 物理防治（防虫网、粘虫板）
- 化学防治（低毒农药、轮换用药）
- 农业防治（水肥管理、修剪清园）

**4. 安全间隔**
- 农药安全间隔期提醒
- 采收前禁止用药天数
- 不同农药类型的安全间隔对比表

##### 防治日历
- 按时间轴排列的预防措施建议
- 每个条目包含：日期、措施类型（预防/监测/防治）、具体操作说明
- 颜色编码区分措施优先级
- 支持标记"已完成"

### 6.4 农事操作

**路由**：`/v2/operations`

#### 页面功能
基于模拟结果和物候阶段，智能推荐灌溉、施肥、修剪、植保等农事操作方案。帮助种植户科学安排农事计划，提高产量和品质。

#### 组件说明

##### 指标卡片（5个关键参数）
| 卡片 | 含义 |
|------|------|
| 灌溉方式 | 推荐灌溉方式（滴灌/喷灌/漫灌） |
| 施N量 | 全生育期推荐氮肥施用量（kg/ha） |
| 覆膜 | 推荐覆膜类型（黑色/白色/透明地膜） |
| 密度 | 当前配置种植密度（株/ha） |

##### 阶段时间轴色条
- 水平色条展示全生育期的阶段分布
- 不同颜色代表不同物候阶段
- 当前阶段高亮显示
- 每个阶段标注起止日期

##### 操作卡片网格（按阶段分组）
按生长阶段分组展示操作建议：

**定植前阶段**
- 整地、起垄、土壤消毒、基肥施用

**营养生长期**
- 氮肥追施、灌溉调度、蚜虫监测、杂草管理

**开花期**
- 增钾减氮、灰霉病预防喷药、调节EC值、授粉管理

**结果期**
- 调整灌溉EC、增加排液率、炭疽病防治、果实保护

**采收期**
- 采收调度、品质监测、持续灌溉、冷链准备

**采收后**
- 修剪清园、土壤改良、休耕管理

每张操作卡片包含：
- **操作类型图标**：灌溉💧 / 施肥🧪 / 修剪✂️ / 采收🧺 / 植保🛡️ / 其他
- **操作名称和描述**
- **优先级标签**：🟢低 / 🟡中 / 🔴高 / ⚡紧急
- **执行日期或时间窗口**
- **具体参数**：灌溉量、EC值、NPK比例等

##### 灌溉方案表格
| 列 | 内容 |
|---|------|
| 日期 | 灌溉执行日期 |
| 灌溉量(mm) | 单次灌溉量 |
| EC值 | 灌溉水EC值(mS/cm) |
| 方式 | 滴灌/喷灌 |

##### 施肥方案表格
| 列 | 内容 |
|---|------|
| 日期 | 施肥执行日期 |
| 氮磷钾比例 | N-P₂O₅-K₂O 比例 |
| 施用量(kg/ha) | 肥料用量 |
| 施肥方式 | 基肥/追肥/叶面肥 |

## 7. 链式决策流程

版本二的核心设计理念是**"物候→产量→病虫害→农事操作"**的链式决策闭环：

```
┌─────────────────────────────────────────────────────────┐
│                    链式决策引擎                          │
│                                                         │
│  ┌──────────┐     ┌──────────┐     ┌──────────┐        │
│  │ 物候方案  │────▶│ 产量预测  │────▶│ 植保IPM  │        │
│  │ (驱动核心)│     │ (结果输出)│     │ (风险预警)│        │
│  └─────┬────┘     └──────────┘     └────┬─────┘        │
│        │                                │              │
│        ▼                                ▼              │
│  ┌──────────────────────────────────────────────┐     │
│  │              农事操作推荐                      │     │
│  │  (综合物候阶段+产量目标+病虫害风险)             │     │
│  └──────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### 决策流说明

1. **物候方案（驱动核心）**：GDD模型计算各生长阶段时间节点，是所有后续决策的**数据基础**。阶段转换触发不同的产量模式、病虫害风险和农事操作。

2. **产量预测（结果输出）**：基于物候阶段和气象条件，预测逐日产量和品质。第一/二茬产量占比直接影响采收计划和市场策略。

3. **植保IPM（风险预警）**：根据**物候阶段 + 气象条件 + 品种抗性**综合评估病虫害风险。例如：
   - 开花期 + 高湿 → 灰霉病高风险
   - 高温干旱 → 红蜘蛛高风险
   - 结果期 + 降雨 → 炭疽病高风险

4. **农事操作（综合推荐）**：整合以上三个维度的信息，生成具体的操作建议：
   - 物候阶段决定"什么时候做"
   - 产量目标决定"做到什么程度"
   - 病虫害风险决定"额外需要做什么"

## 8. 核心算法

版本二使用与版本一完全相同的 DSSAT CROPGRO-Strawberry 模型引擎，额外增加了：

| 模块 | 功能 | 版本二新增 |
|------|------|-----------|
| 物候发育 | GDD计算、阶段转换 | ✅ 共享 |
| 光合生产 | 冠层光合、呼吸、分配 | ✅ 共享 |
| 土壤水分 | PET、蒸发、蒸腾、径流 | ✅ 共享 |
| 土壤氮素 | 矿化、硝化、吸收 | ✅ 共享 |
| 草莓专用 | 连续开花、多次采收 | ✅ 增强版（光热年龄） |
| 品质预测 | SSC、酸度、硬度 | ✅ 共享 |
| 胁迫因子 | 水/氮/温度胁迫 | ✅ 共享 |
| **病虫害风险** | 5种病虫害阶段+气象风险预警 | 🆕 新增 |
| **农事操作** | 基于阶段和风险的智能推荐 | 🆕 新增 |

### 病虫害预警逻辑

| 病虫害 | 高风险条件 | 关联阶段 |
|--------|-----------|----------|
| 灰霉病 | 开花期 + 高湿 + 15-25°C | 开花期、结果期 |
| 白粉病 | 干燥 + 温暖 + 低湿 | 营养生长期 |
| 红蜘蛛 | 高温 + 干旱 | 全生育期 |
| 炭疽病 | 结果期 + 降雨 | 结果期、采收期 |
| 蚜虫 | 温暖春季 | 营养生长期、开花期 |

### 农事操作推荐逻辑

| 生长阶段 | 推荐操作 |
|----------|----------|
| 定植前 | 整地、起垄、土壤消毒 |
| 营养生长期 | 氮肥追施、灌溉调度、蚜虫监测 |
| 开花期 | 增钾减氮、灰霉病预防喷药、调节EC |
| 结果期 | 调整灌溉EC、增加排液率、炭疽病防治 |
| 采收期 | 采收调度、品质监测、持续灌溉 |
| 采收后 | 修剪、清园、土壤改良 |
